RO-BIO website update (round 5, includes every earlier round)

What's new
  - The robot arm on the home page is now a real 3D arm with five joints
    and a two-finger gripper. Tap the vial, the block or the ball (or use
    the buttons under it) and it picks it up and puts it in the tray.
    Manual mode lets you drive it yourself: hold to grip, let go to drop.
  - The venue map shows straight away on Contact and Bot Forge. No more
    "Show the map" button.
  - New Join page (/join) with reasons to join, who to contact, and a QR
    code. "Join" is in the menu and on the home page.
  - Printable QR files: public/qr/robio-qr-card.svg (poster with logo),
    robio-qr.png and robio-qr.svg. Scanning opens the website.
  - From the club's Word file: "What we work on" (home and About), and
    vision and mission (About).

1. Unzip this file. Copy everything inside it (except this text file) into
   your local Ro-Bio folder, the one GitHub Desktop uses. Choose "Replace"
   when Windows or macOS asks.

2. Nothing needs deleting this time.

3. Open GitHub Desktop. In the Changes list, check that you can see:
     package.json and package-lock.json
     src/lib/arm-sim.ts (new)
     src/components/site/arm-scene.ts (new)
     src/routes/join.tsx (new)
     public/qr/ (new, three files)
     docs/screenshots/ (updated images)

4. Write a short summary, for example:
     3D robot arm, map on by default, Join page and QR code
   then click "Commit to main" and "Push origin".

5. Cloudflare deploys it by itself in a minute or two. Open
   https://ro-bio.robiohub2026.workers.dev and press Ctrl+F5 once.
   Check: the arm loads (it appears a moment after the page), the map
   shows on /contact, and /join opens.

If the web address ever changes (a custom domain), update "url" in
src/lib/site.ts. The QR files are rebuilt on every deploy, but reprint any
posters you already made.
