RO-BIO website update (round 6)

What's new
  - Robot arm: no more modes. Tap a sample to pick it up, then tap where
    it should go. With a mouse the sample follows the cursor, and dragging
    works too. The arm glides smoothly and always puts things down gently.
    The buttons under it still send each sample to the tray.
  - QR code removed from the whole site.
  - Join page and Join button removed.
  - Bot Forge shows "Date coming soon" everywhere.
  - Tighter layouts on Home, Events, Bot Forge, Team, Contact and Blog.

Steps
1. FIRST, DELETE these files from your Ro-Bio folder. This step matters:
   if src/routes/join.tsx is left behind, the website will not build.
     src/routes/join.tsx
     src/components/site/QrCode.tsx
     src/lib/qr.ts
     scripts/build-qr.mjs
     docs/screenshots/join.jpg
     public/qr   (the whole folder, with its 3 files)

2. Unzip this file. Copy everything inside it (except this text file) into
   your local Ro-Bio folder, the one GitHub Desktop uses. Choose "Replace"
   when Windows or macOS asks.

3. Open GitHub Desktop. In the Changes list you should see:
     the 6 deleted files above, shown in red
     src/lib/arm-sim.ts and src/components/site/RobotArm.tsx
     src/lib/site.ts (Bot Forge date)
     package.json and package-lock.json
     docs/screenshots/ (updated images)

4. Write a short summary, for example:
     Easier robot arm, no QR or Join, Bot Forge date coming soon
   then click "Commit to main" and "Push origin".

5. Cloudflare deploys it by itself in a minute or two. Open
   https://ro-bio.robiohub2026.workers.dev and press Ctrl+F5 once.
   Check: tap the ball, then tap the tray. Check /events/bot-forge says
   "Date coming soon".

When Bot Forge has a date: in src/lib/site.ts change  date: null,
to the date in quotes, for example  date: "2026-12-04",
